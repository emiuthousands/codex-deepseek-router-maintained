# Codex DeepSeek Router — Marketplace Edition

This package is the Skills-only, Desktop-only edition prepared for the OpenAI
Plugin Directory.

It supports Codex 0.149 and newer through the Desktop-compatible
`direct_codex` transport. The complete GitHub distribution continues to provide
the legacy Hook transport for compatible older Codex versions.

No lifecycle Hook is included in this package.

See `PRIVACY.md`, `TERMS.md`, `NOTICE.md`, and `LICENSE` for data, provenance,
and licensing information.
